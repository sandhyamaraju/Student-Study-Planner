# 🎓 Student Study Planner

A responsive web application designed to help students organize and track their daily study tasks.

## 🚀 Features

* ➕ Add study tasks
* 📚 Add subjects
* 📅 Set study dates
* ✅ Mark tasks as completed
* ↩️ Undo completed tasks
* 🗑️ Delete tasks
* 📊 Track study progress
* 🔍 Search tasks
* 🔘 Filter All, Pending, and Completed tasks
* 🌙 Dark Mode / ☀️ Light Mode
* 💾 Save tasks using LocalStorage
* 📱 Responsive design for mobile and desktop

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* LocalStorage
